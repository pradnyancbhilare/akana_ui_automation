We have supported Firefox browser using geckodriver and Chrome browser using chromedriver on three different flavors of OS.

Linux
======
Geckodriver 	= 	geckodriver-v0.28.0-linux64
Chromedriver 	= 	chromedriver_linux64_87


Windows
========
Geckodriver 	= 	geckodriver-v0.28.0-win64
Chromedriver 	= 	chromedriver_win32_87


Mac OS
========
Geckodriver 	= 	geckodriver-v0.28.0-macos
Chromedriver 	= 	chromedriver_mac64_87
